Guia Básico de Tags HTML

Entenda as principais tags utilizadas em HTML

<html>

Define o início de um documento HTML. Tudo deve estar dentro dessa tag.

<head>

Contém informações sobre o documento, como título, metadados e links para estilos.

<title>

Define o título da página, exibido na aba do navegador.

<body>

Contém todo o conteúdo visível da página.

<h1> até <h6>

São usadas para títulos e subtítulos, sendo <h1> o mais importante.

<p>

Define um parágrafo de texto.

<a>

Cria links. Exemplo: <a href="https://google.com">Ir para o Google</a>

<img>

Exibe imagens. Exemplo: <img src="imagem.jpg" alt="Descrição">

<ul>, <ol>, <li>

Usadas para listas não ordenadas e ordenadas.

<div>

Elemento genérico usado para organizar o layout da página.

<span>

Elemento inline usado para estilizar partes específicas do texto.
